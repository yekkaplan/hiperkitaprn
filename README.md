# Hiperkitap React Native

Türkiye'nin ilk dijital kütüphanesi Hiperkitap'ın mobil uygulaması.

## 🚀 Özellikler

- Modern ve kullanıcı dostu arayüz
- 30.000'den fazla e-kitap
- Çoklu platform desteği (iOS, Android)
- Kişiselleştirilmiş okuma deneyimi
- Not alma ve işaretleme özellikleri
- 7/24 erişim imkanı

## 🛠 Teknolojiler

- React Native
- TypeScript
- React Navigation
- React Native Reanimated
- MMKV Storage
- Plus Jakarta Sans & Outfit Font Ailesi

## 🚀 Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/your-username/hiperkitaprn.git
cd hiperkitaprn
```

2. Bağımlılıkları yükleyin:
```bash
npm install
# veya
yarn install
```

3. iOS için pod'ları yükleyin:
```bash
cd ios && pod install && cd ..
```

4. Uygulamayı başlatın:
```bash
# iOS
npm run ios
# veya
yarn ios

# Android
npm run android
# veya
yarn android
```

## 📁 Proje Yapısı

```
src/
├── components/     # Yeniden kullanılabilir bileşenler
├── navigation/     # Navigasyon yapılandırması
├── screens/        # Ekran bileşenleri
├── theme/          # Tema ve stil tanımlamaları
├── types/          # TypeScript tip tanımlamaları
└── utils/          # Yardımcı fonksiyonlar
```
